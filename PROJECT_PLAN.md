## 1. Project Overview

The purpose of this project is to segment customers into meaningful groups based on their purchasing behavior.

By identifying customers with similar behavioral characteristics, businesses can better understand differences across their customer base and develop targeted marketing strategies instead of relying on a one-size-fits-all approach.

The project combines **SQL, data analysis, feature engineering, unsupervised machine learning, marketing analytics, Excel, and Tableau** to transform raw e-commerce transactions into actionable customer segments.

---

## 2. Business Problem

Companies often serve customers with significantly different purchasing behaviors.

Some customers:

- Spend large amounts but purchase only once.
- Purchase repeatedly and demonstrate loyalty.
- Purchase recently but generate relatively low value.
- Become inactive after their first transaction.
- Generate substantial historical value but later become inactive.

Treating these customers with the same marketing strategy can result in inefficient marketing spending and irrelevant campaigns.

Customer segmentation provides a data-driven approach for identifying these differences and developing appropriate strategies for each customer group.

## 5. Feature Engineering

The transactional database was transformed into a customer-level analytical dataset.

Each final row represents one customer.

The primary clustering features were:

### Total Orders

The total number of orders associated with each customer.

**Marketing meaning:** Purchase frequency.

### Total Spent

The total monetary value generated by each customer.

**Marketing meaning:** Customer monetary value.

### Average Order Value

The average amount spent per order.

```text
Average Order Value = Total Spent / Total Orders
```

**Marketing meaning:** Typical transaction value.

### Recency

The number of days representing how recently the customer purchased relative to the analysis reference date.

**Marketing meaning:** Customer activity or inactivity.

These features collectively capture important dimensions of customer purchasing behavior:

**Monetary Value + Frequency + Transaction Size + Recency**

## 6. Machine Learning Approach

### Learning Type

**Unsupervised Machine Learning**

No predefined customer segment labels were available. The objective was to discover naturally occurring patterns within customer purchasing behavior.

### Algorithm

**K-Means Clustering**

### Why K-Means?

K-Means was selected because:

- The project required discovering customer groups without predefined labels.
- The engineered features are numerical.
- Customers can be compared based on similarity in multidimensional feature space.
- K-Means provides interpretable cluster centroids.
- It is widely applicable to behavioral customer segmentation.

### Distance Metric

**Euclidean Distance**

K-Means assigns each customer to the nearest cluster centroid based on distance in the standardized feature space.

### Feature Scaling

The clustering features operated on different numerical scales.

`StandardScaler` was therefore applied before clustering to prevent variables with larger magnitudes from disproportionately influencing distance calculations.

### K-Means From Scratch

Before using Scikit-learn, the main K-Means algorithm was implemented manually to understand:

- Centroid initialization
- Euclidean distance calculations
- Cluster assignment
- Centroid recomputation
- Iterative convergence

### Number of Clusters

Candidate values of K were evaluated using the **Elbow Method**.

The final selected number of clusters was:

**K = 5**

## 8. Final Customer Segments

The final model identified five behavioral customer segments.

| Segment | Customers | Avg. Spending | Avg. Orders | Avg. Recency |
|---|---:|---:|---:|---:|
| High-Value Lapsed Customers | 13,187 | 515.3 | 1.000 | 317.8 days |
| Inactive Low-Value Customers | 22,904 | 99.0 | 1.000 | 479.7 days |
| Loyal Repeat Customers | 2,997 | 315.0 | 2.116 | 268.7 days |
| Recent Low-Value Customers | 25,533 | 50.7 | 1.000 | 218.1 days |
| Recent Mid-Value Customers | 31,474 | 149.6 | 1.000 | 195.2 days |

### High-Value Lapsed Customers

Customers with the highest average spending but relatively long inactivity and limited repeat purchasing.

**Primary objective:** Reactivation.

### Inactive Low-Value Customers

Customers with relatively low historical spending and the longest inactivity.

**Primary objective:** Cost-efficient win-back.

### Loyal Repeat Customers

Customers with the highest purchase frequency and strong spending.

**Primary objective:** Retention and customer lifetime value growth.

### Recent Low-Value Customers

Relatively recent customers with low monetary value and approximately one purchase.

**Primary objective:** Second-purchase conversion and basket growth.

### Recent Mid-Value Customers

The largest customer segment, combining relatively recent purchasing activity with moderate monetary value.

**Primary objective:** Convert recent customers into repeat purchasers.
